## Introduction

Mars2D is a free 2D map client development platform, enhanced from [Leaflet](http://leafletjs.com/) with a B/S architecture. It is a lightweight, high-performance GIS development platform that supports multi-industry extension, big-data visualization and real-time streaming visualization, enabling beautiful and smooth map rendering and spatial analysis on browsers and mobile devices.

- Website: [http://mars2d.cn](http://mars2d.cn)
- Tutorials: [http://mars2d.cn/dev/](http://mars2d.cn/dev/)
- API docs: [http://mars2d.cn/api/](http://mars2d.cn/api/)
- Changelog: [CHANGE.md](./CHANGE.md)
- Issues: [GitHub Issues](https://github.com/marsgis/mars2d/issues)

All Mars2D materials and code are free and open source; this repository also serves as the navigation page for Mars2D open-source repositories.
